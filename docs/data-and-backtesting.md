# 数据规范与回测约定

## 输入

行情 CSV 需要 `date` 列；Pickle 需要 pandas DataFrame，可为 DatetimeIndex，也兼容包含 `date` 层的 MultiIndex。期货主力数据在规范化后必须每天一条记录。原始表不被就地修改。

- 指数：`close`。
- 期货：`close`，以及所选特征依赖的 `open/high/low/settlement`。
- 股票：`date, sec_code, open, high, low, close, volume`；`order_book_id` 或 `stock` 在边界统一改为 `sec_code`。
- 权重：`date, sec_code, weight`，同日同股票不能重复，权重必须有限且非负。允许 1 或 100 为单位的完整权重表，按当日正权重总和归一化。
- 成分表：以日期索引、证券代码为列的布尔表，true 表示成员；等权模式优先使用该表。

核心价格必须有限且大于零，high 不得小于 low；不把缺失价格填成零。期货与指数先取共同起止区间，区间内部交易日必须完全一致，不按行数截尾、不默默合并掉缺失日期。模型输入在特征预热结束后必须有限，常量因子报错。

只支持 CSV 和显式允许的可信 Pickle。Pickle 可以执行任意 Python 反序列化代码，不能加载不可信来源。既有数据保持 `data/` 下原路径；重构没有复制或删除行情文件。

## 时间约定与收益

当日收盘后计算特征和信号。状态编号是每次模型拟合局部的标签，不跨窗口赋予固定“牛/熊”含义。训练状态通过下一日的训练期指数收益映射为持有或现金；最后一个训练状态没有训练内下一日收益。固定阈值比较的是每个状态对应日收益累乘的净值；benchmark 模式比较相同可用区间的基准净值。没有观测的状态默认现金。

样本外使用前向过滤 `P(state_t | observation_1..t)`，不使用整段 Viterbi 或平滑后验。测试块共用训练好的参数，模型在每个块开始前重新训练。首个测试日之前没有样本外信号，仓位为零；后续持仓统一滞后一天。最后不足完整窗口的交易日也全部计算。

指数近似回测使用下一日 close-to-close 收益，换仓时按仓位变化收取单边佣金与滑点，费用先从本金扣除再计算收益。它不是可直接成交的执行模型，因为收盘后信号不能成交在已经过去的收盘价。输出的 `signal` 是当日决策，`position` 是当日计收益的仓位，`turnover` 是仓位变动绝对值。交易次数按实际仓位变动计，不再把持有天数算作交易次数。

## 股票组合执行

`portfolio` 命令使用相同信号，Backtrader 在下一交易日开盘尝试成交，包含配置佣金和滑点。每个持有日按最新已知成分快照调仓；权重更新同时调整已有持仓，而不只是首次买入。卖出先于买入提交，目标股数按 `lot_size` 向下取整，预留 `cash_reserve` 现金。期末不强制清仓，最后一天信号不产生区间内成交。

缺失行情只用历史收盘价做估值，成交量设为零；不向前填充上市前价格，停牌日不允许成交。尚无可交易价格的成分保留现金，下一可交易日再尝试。保证金不足或拒单保留日志和订单状态，实际收益以真实成交为准。权重快照日期需代表当日收盘前已知信息；若数据源日期代表未来生效时间，应在数据准备时处理。

当前组合模拟未实现涨跌停排队、真实成交量限制、印花税差异、公司行动现金分红或实时交易接口。使用复权价格做研究模拟，手数与真实未复权交易可能不同。指数近似指标与组合指标分别输出。

## 指标与搜索

净值从 1 开始，回撤峰值包含初始本金，因此首日亏损也计入回撤。年化收益按配置交易日数计算；波动率使用日收益总体标准差；夏普使用日超额收益平均值年化后除以年化波动率，零波动时记 0。

参数搜索独立运行每组配置，输出成功状态或具体错误。网格会显式切换到固定信号阈值；`pca_variances` 不填写时默认关闭 PCA。搜索只改变阈值、训练/测试窗口和 PCA 阈值，因子组合通过不同 TOML 表达。搜索报告不自动宣称最优参数，也没有嵌套交叉验证；正式比较需保留独立验证区间。

HMM 官方 API：[hmmlearn GaussianHMM 实现](https://github.com/hmmlearn/hmmlearn/blob/main/src/hmmlearn/hmm.py)。过滤器通过公开的 startprob_、transmat_、means_、covars_ 实现，并与逐前缀 `score_samples` 的末日后验做回归比较。
